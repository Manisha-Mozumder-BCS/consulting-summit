# Consulting Ecosystem Summit 2026

Landing page for the **Consulting Ecosystem Summit 2026**, hosted by **Manisha Mozumder Business Consulting Services**.

**Location:** Berlin, Germany

## About

A one-day summit bringing together consulting firms, startups, investors, students and industry experts to build a stronger consulting ecosystem.

**Connect. Collaborate. Grow Together.**

## Tech Stack

- **React 18** + **TypeScript**
- **Vite** (build tool)
- **Tailwind CSS** (styling)
- **Lucide React** (icons)

## Getting Started

### Prerequisites

- Node.js 18+ and npm

### Installation

```bash
npm install
```

### Development

```bash
npm run dev
```

Opens at [http://localhost:5173](http://localhost:5173)

### Production Build

```bash
npm run build
```

The production-ready files will be in the `dist/` folder.

### Preview Production Build

```bash
npm run preview
```
